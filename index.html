NexScript: your own indicators and strategies

A small, readable language made for charts. Write it in the built-in editor, run it, and it lands on the chart like any indicator. Errors and messages appear in your language.

Strategies can be backtested, with results scored in risk units, and optimised across settings.

nexscript "EMA cross" strategy
param fast: int = 12 range 2..100
param slow: int = 26 range 3..300

let fastLine = ema(close, fast)
let slowLine = ema(close, slow)
draw line fastLine color orange width 2
draw line slowLine color blue

go long when crossUp(fastLine, slowLine)
go flat when crossDown(fastLine, slowLine)
